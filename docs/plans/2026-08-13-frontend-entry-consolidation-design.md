# 前端入口收敛设计

## 背景与目标

项目当前同时保留 `index.html` 与旧版 `music_viewer.html`，以及统一编辑器 `editor.html` 和两个早期独立编辑页。歌曲页两份实现有两千余行重复代码，旧版还缺少新版已有的清空筛选、语义化排序按钮和键盘展开能力；两个独立编辑页则已经由统一编辑器完整覆盖。

本阶段不重做视觉，也不改变数据结构。目标是把运行时实现收敛到主页、视频页和统一编辑器，同时让旧书签、旧文档链接与部署地址继续工作。

## 页面与导航方案

三个旧页面改成轻量兼容页。页面提供即时 JavaScript 跳转、`meta refresh` 降级以及明确的手动链接。跳转保留原网址上的查询参数和锚点；编辑器旧入口会追加对应的 `tab=video` 或 `tab=alias`。

统一编辑器把标签页状态交给 URL：初始化时读取 `tab`，点击标签时用 History API 更新地址但不刷新页面。未知 `tab` 自动回落到视频补录。按钮使用 `role="tablist"`、`role="tab"`、`aria-selected` 和方向键切换，保留当前视觉风格并改善键盘访问。

## 兼容与验证

旧页面仍由站点白名单发布，因此现有外部链接不会 404。自动测试检查三个映射、查询参数/锚点保留逻辑，以及编辑器对合法和非法标签值的处理。最后通过本地服务器验证实际 302 等价跳转结果、目标标签激活、主页数据加载及浏览器控制台无错误。
