# 前端数据展示修复设计

## 范围

保持现有静态 HTML、JSON 数据结构和视觉语言不变，修复视频遗漏，并改善搜索、筛选和键盘操作。歌曲详情形态与首页信息架构不在本批范围。

## 数据关联

视频页以 `database_v2.json` 的歌曲和视频为遍历真源。先按 `sekaiMusicId` 对应 `combined_music_data.json` 的数字 `id`，再按标准化标题回退。匹配成功时补充标签、分类和创作者；匹配失败时仍生成视频行，并标记 `isUnmatched`。页面展示数据库视频总数、已展示数和待关联数，禁止静默丢弃。

## 交互

歌曲页和视频页为搜索框增加持久标签、清空按钮和筛选摘要。侧栏增加清空筛选按钮。排序标题使用原生按钮并维护 `aria-sort`。可展开行增加 `tabindex`、按钮角色、`aria-expanded`，并支持 Enter/Space。

## 验证

使用离线脚本检查数据库视频总数与前端关联结果；运行现有 Python unittest。通过本地服务器在应用内浏览器验证视频总数、搜索清空、筛选清空、排序和键盘展开，并捕获修改后的歌曲页及视频页截图。
