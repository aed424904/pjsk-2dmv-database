# 字段
- 最重要的一个问题是，我需要哪些字段,它们有什么用，我又需要展示哪些字段？一首歌能有哪些字段，有没有做不到的可能性？
## musics.json
- id 唯一id
- seq 序号
- categories MV类型（重要）
- title 歌曲标题
- creatorArtistId 创作者id 关联另一个表 musicArtists.json
    - | `lyricist` | string | 作词者 |
    - | `composer` | string | 作曲者 |
    - | `arranger` | string | 编曲者（无则为 `"-"`） |
- dancerCount 舞者数量
- publishedAt 游戏内发布时间戳（毫秒）（注意时差）
- releasedAt 原曲发布时间戳（毫秒）
- liveStageId Live舞台ID（可以用来？对应文件里面只有v和ln何意味）
- isNewlyWrittenMusic 是否为游戏原创书写下曲目
- isFullLength 是否为完整版

## musicVocals.json
- id 版本唯一id
- musicId 关联的音乐id
- musicVocalType 歌声类型
    - 
- caption 版本描述
- characters 演唱角色列表（嵌套对象）
- characters[].id 角色-歌声关联记录id
- characters[].musicId 关联音乐id
- characters[].musicVocalId 关联歌声版本id
- characters[].characterType 角色类型
- characters[].characterId 角色id
- characters[].seq 角色排序
- assetbundleName 音频资源包名
- archivePublishedAt 音乐归档发布时间戳（毫秒）
