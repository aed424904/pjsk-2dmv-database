## 设计总览

搜索面板以**可折叠侧边栏**的形式嵌入现有页面（替换或增强当前侧边栏），分为 **4 个大区块**，按使用频率从高到低排列：

| 区块 | 包含筛选器 | 交互形式 |
|------|-----------|---------|
| **① 关键词搜索** | 歌曲名/创作者 | 文本输入框 |
| **② 标签筛选** | 团体、版本类型、MV类型、歌曲分类 | 多选按钮(Chip/Toggle) |
| **③ 角色筛选** | 演唱角色 | 可搜索的多选下拉 |
| **④ 数值区间** | 发布时间 | 日期区间选择器 |

---

## ① 关键词搜索区

### 歌曲名搜索
- **交互**: 单行文本输入框，带搜索图标
- **占位符**: `歌曲名を入力 / 输入歌曲名...`
- **匹配字段**: `title`
- **逻辑**: 模糊匹配（`includes`），不区分大小写
- **备注**: 未来可扩展别名（aliases）字段来支持罗马音/中文译名搜索

### 创作者搜索
- **交互**: 单行文本输入框
- **占位符**: `P主 / 作词 / 作曲 / 编曲...`
- **匹配字段**: `creators.creatorArtistName`, `creators.lyricist`, `creators.composer`, `creators.arranger`
- **逻辑**: 任一字段命中即显示

## ② 标签筛选区（多选 Toggle Chips）

> 所有 Toggle 默认为**全不选 = 不限制**（即显示全部）。选中任意一个或多个则只显示匹配条目。

### 演唱团体 (Group Tags)

基于现有 `tags` 字段的值，映射为用户可读的团体名：

| tags 原始值 | 显示名 | 配色 |
|------------|--------|------|
| `light_music_club` | Leo/need | 🔴 `#FF6155` |
| `idol` | MORE MORE JUMP! | 🟢 `#6CC94D` |
| `street` | Vivid BAD SQUAD | 🟠 `#EE8844` |
| `theme_park` | ワンダショ / WxS | 🟡 `#FFD43B` |
| `school_refusal` | 25時 / N25 | 🟣 `#9B6DFF` |
| `vocaloid` | VIRTUAL SINGER | 🔵 `#38D9E8` |

- **多选逻辑**: OR（选了 L/N 和 VBS → 显示属于 L/N **或** VBS 的歌）

### 版本类型 (Vocal Type)

基于 `vocals[].musicVocalType` 字段：

| 原始值 | 显示名 | 说明 |
|--------|--------|------|
| `original_song` | VS原唱 | バーチャル・シンガーver. |
| `sekai` | Sekai版 | セカイver. |
| `another_vocal` | Another Vocal | アナザーボーカルver. |
| `virtual_singer` | VS合唱 | VS多人版 |
| `instrumental` | 伴奏 | inst版 |
| `april_fool_*` | 愚人节 | エイプリルフールver. |
| `streaming_live` | Connect Live | コネクトライブver. |

- **作用范围**: 当选中某些版本类型后，只筛选出**包含**对应版本的歌曲
- **多选逻辑**: OR

### MV 类型 (Categories)

基于 `categories` 数组字段：

| 原始值 | 显示名 | 说明 |
|--------|--------|------|
| `mv` | 3DMV | 有3D MV |
| `mv_2d` | **2DMV** ⭐ | 有2D MV（本数据库核心关注点） |
| `image` | 静态图 | 仅有静态背景图 |
| `original` | 原版MV | 使用原版MV |

- **多选逻辑**: OR（选了 2DMV + 3DMV → 显示有 2DMV **或** 3DMV 的歌）
- **特殊用法**: 单选 `mv_2d` 即可快速筛出所有拥有 2DMV 的歌曲

### 歌曲分类 (Song Origin)

基于 `isNewlyWrittenMusic` 字段 + `tags` 推断：

| 条件 | 显示名 |
|------|--------|
| `isNewlyWrittenMusic === true`（如有） | 书下曲 (Commission) |
| `tags` 包含 `vocaloid` | VOCALOID曲 |
| 其他 | 翻唱/授权曲 |

- **典型用途**: 找某角色的 Solo 曲（选角色 + 人数=1）

## ④ 数值区间筛选区

### 游戏内发布时间 (Published At)
- **交互**: 双日期选择器（起始日期 — 结束日期）
- **数据来源**: `publishedAt`（毫秒时间戳，前端转为日期显示）
- **典型用途**: "看看 2023 年实装了哪些新歌"

### 原曲发布时间 (Released At)
- **交互**: 双日期选择器
- **数据来源**: `releasedAt`（毫秒时间戳）
- **典型用途**: "有没有 2010 年之前的老歌被收录？"

## 底部操作栏

| 按钮 | 样式 | 功能 |
|------|------|------|
| **重置** | 描边按钮（outline） | 清空所有筛选条件，恢复默认 |
| **搜索** | 渐变填充按钮（accent色） | 执行搜索并更新右侧结果列表 |

> **可选方案**: 也可做成**实时筛选**（用户每点一个条件就立即更新结果，无需点「搜索」按钮），去掉搜索按钮，只保留重置按钮。由于数据量不大（~400首歌），实时筛选不会有性能问题。

## 组合查询示例

以下演示用户如何通过搜索面板完成之前讨论过的复杂搜索需求：

| # | 用户需求 | 操作步骤 |
|---|---------|---------|
| 1 | "千本樱被 VBS 翻唱过吗？" | 歌名输入`千本樱` → 团体选`VBS` → 版本选`Sekai版` |
| 2 | "DECO*27 有哪些 2DMV？" | 创作者输入`DECO*27` → MV类型选`2DMV` |
| 3 | "初音ミク 独唱的 Another Vocal" | 角色选`初音ミク` → 版本选`Another Vocal` → 人数选`1人` |
| 4 | "2023 年实装的 N25 书下曲" | 团体选`N25` → 分类选`书下曲` → 发布时间设为`2023-01-01 ~ 2023-12-31` |
| 5 | "Leo/need 和 MMJ 联动过的跨团曲" | 团体同时选`L/N` + `MMJ` → 版本选`Sekai版`或`愚人节版` |
| 6 | "アナザーボーカル 由两人合唱" | 版本选`Another Vocal` → 人数选`2人` |

## 当前数据的局限与未来扩展

以下字段是当前 `combined_music_data.json` 中 **尚未有** 但推荐未来补充的字段：

| 推荐字段 | 用途 | 优先级 |
|---------|------|--------|
| `aliases` (别名数组) | 支持罗马音、中文译名搜索 | ⭐⭐⭐ 高 |
| `bpm` | BPM 区间筛选, 找快歌/慢歌 | ⭐⭐ 中 |
| `duration` (时长) | 时长区间筛选 | ⭐⭐ 中 |
| `illustrator` / `movieMaker` | 搜索 2DMV 画师/MV制作者 | ⭐⭐⭐ 高（核心卖点） |
| `difficulty` (各难度等级) | 按谱面难度筛选 | ⭐ 低 |
| `noteCount` (物量) | 找特定物量范围的歌 | ⭐ 低 |

> [!TIP]
> 前 4 个级别的筛选器（关键词 + 标签 + 角色 + 时间区间）已经可以覆盖绝大多数用户的日常查询需求。BPM 等数值型字段属于"锦上添花"，可以后续逐步补充。
